# SolarOS ERP

SolarOS ERP is a production-oriented Solar EPC Management Platform that
streamlines the complete solar installation lifecycle:

- **Customer acquisition** — capture leads, opportunities, contacts, and
  follow-ups.
- **Site surveys** — record site details, constraints, measurements, and
  survey findings.
- **Solar system configuration** — configure system components and
  installation requirements.
- **Quotations** — prepare and manage customer proposals and pricing.
- **Inventory and procurement** — track stock, warehouse operations,
  suppliers, purchase orders, and end-to-end inventory control.
- **Project execution** — plan work, coordinate resources, and monitor project
  progress.
- **Installation** — manage installation milestones and completion records.
- **Warranty management** — track warranties and customer equipment coverage.
- **After-sales service** — handle service requests, work, and customer
  support.
- **Financial analytics** — provide visibility into costs, margins, revenue,
  and project performance.
